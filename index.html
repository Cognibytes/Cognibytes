Algebra Formula Sheet

Important formulas and identities commonly used in Algebra I and Algebra II.

Distributive Property: a(b + c) = ab + ac
Difference of Squares: a² − b² = (a − b)(a + b)
Perfect Square: a² + 2ab + b² = (a + b)²
Perfect Square: a² − 2ab + b² = (a − b)²
Slope: m = (y₂ − y₁) / (x₂ − x₁)
Slope-Intercept: y = mx + b
Point-Slope: y − y₁ = m(x − x₁)
Quadratic Formula: x = (−b ± √(b² − 4ac)) / 2a
Distance: d = √((x₂ − x₁)² + (y₂ − y₁)²)
Midpoint: ((x₁ + x₂)/2, (y₁ + y₂)/2)

Exponent Rules

These rules are essential for simplifying expressions with powers.

Product Rule: aᵐ · aⁿ = aᵐ⁺ⁿ
Quotient Rule: aᵐ / aⁿ = aᵐ⁻ⁿ
Power Rule: (aᵐ)ⁿ = aᵐⁿ
Zero Exponent: a⁰ = 1
Negative Exponent: a⁻ⁿ = 1/aⁿ
Power of a Product: (ab)ⁿ = aⁿbⁿ
Power of a Quotient: (a/b)ⁿ = aⁿ/bⁿ
Example:
x³ · x⁴ = x⁷
Example:
x⁸ / x³ = x⁵

Factoring Guide

Factoring rewrites an expression as a product of simpler expressions.

1. Greatest Common Factor

Example:
6x² + 9x

GCF = 3x
= 3x(2x + 3)

2. Difference of Squares

a² − b² = (a − b)(a + b)
Example:
x² − 25 = (x − 5)(x + 5)

3. Trinomials

Example:
x² + 5x + 6

Find two numbers that multiply to 6 and add to 5.
2 and 3.

Answer: (x + 2)(x + 3)

4. Grouping

Example:
ax + ay + bx + by
= a(x + y) + b(x + y)
= (a + b)(x + y)

Quadratic Formula

For a quadratic equation written as ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) / 2a

Discriminant

D = b² − 4ac
  • D > 0: Two real solutions
  • D = 0: One real solution
  • D < 0: No real solutions
Example:
x² − 5x + 6 = 0

a = 1, b = −5, c = 6
x = (5 ± √25 − 24) / 2
x = (5 ± 1) / 2

Solutions: x = 3 and x = 2

Functions Reference

A function assigns exactly one output to each input in its domain.

f(x) = expression involving x

Common Function Types

  • Linear: f(x) = mx + b
  • Quadratic: f(x) = ax² + bx + c
  • Exponential: f(x) = abˣ
  • Absolute Value: f(x) = |x|
  • Square Root: f(x) = √x
  • Rational: f(x) = p(x) / q(x)

Domain and Range

Domain = all allowed input values, usually x-values.
Range = all possible output values, usually y-values.

Function Notation

Example:
f(x) = 2x + 3

f(4) = 2(4) + 3
f(4) = 11

Slope & Linear Equations

m = (y₂ − y₁) / (x₂ − x₁)

Slope Types

  • Positive: line rises from left to right.
  • Negative: line falls from left to right.
  • Zero: horizontal line.
  • Undefined: vertical line.

Slope-Intercept Form

y = mx + b

m is the slope and b is the y-intercept.

Example:
y = 3x + 2

Slope = 3
Y-intercept = 2

Parallel and Perpendicular Lines

  • Parallel lines have the same slope.
  • Perpendicular lines have slopes that are negative reciprocals.

Systems of Equations

A system contains two or more equations that must be true at the same time.

Substitution

Solve one equation for one variable, then substitute that expression into the other equation.

Elimination

Add or subtract equations so that one variable cancels.
Example:
x + y = 10
x − y = 2

Add the equations:
2x = 12
x = 6

Substitute:
6 + y = 10
y = 4

Solution: (6, 4)

Possible Solutions

  • One solution: lines intersect once.
  • No solution: parallel lines.
  • Infinitely many: same line.

Triangle & Angle Rules

Triangle Angle Sum

A + B + C = 180°

Exterior Angle Theorem

An exterior angle equals the sum of the two remote interior angles.

Types of Triangles

  • Equilateral: 3 equal sides and 3 angles of 60°.
  • Isosceles: at least 2 equal sides.
  • Scalene: no equal sides.
  • Right: one 90° angle.
  • Acute: all angles less than 90°.
  • Obtuse: one angle greater than 90°.

Special Angle Relationships

  • Complementary: sum is 90°.
  • Supplementary: sum is 180°.
  • Vertical angles: congruent.
  • Linear pair: supplementary.

Coordinate Geometry

Slope

m = (y₂ − y₁) / (x₂ − x₁)

Distance Formula

d = √((x₂ − x₁)² + (y₂ − y₁)²)

Midpoint Formula

M = ((x₁ + x₂)/2, (y₁ + y₂)/2)
Example:
Find the midpoint of (2, 4) and (8, 10).

M = ((2 + 8)/2, (4 + 10)/2)
M = (5, 7)

Quadrants

  • Quadrant I: (+, +)
  • Quadrant II: (−, +)
  • Quadrant III: (−, −)
  • Quadrant IV: (+, −)

Math Glossary

Coefficient: A number multiplied by a variable. Example: 5x → 5 is the coefficient.
Constant: A number without a variable.
Variable: A symbol representing an unknown or changing value.
Expression: A combination of numbers, variables, and operations without an equals sign.
Equation: A mathematical statement showing that two expressions are equal.
Polynomial: An expression made from variables and non-negative integer powers.
Function: A relation where every input has exactly one output.
Domain: The set of possible input values.
Range: The set of possible output values.
Intercept: A point where a graph crosses an axis.
Vertex: The highest or lowest point of a parabola.
Congruent: Same size and shape.
Similar: Same shape but potentially different size.
Hypotenuse: The side opposite the right angle in a right triangle.
Radical: An expression involving a root, such as √x.
Factor: A number or expression multiplied by another to produce a product.
Quadratic: A polynomial equation with degree 2.
